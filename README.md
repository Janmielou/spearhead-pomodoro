# SPEARHEAD

**A tactical-themed Pomodoro timer and mission planner.**

SPEARHEAD turns a normal focus routine into a small command-center workflow. Create a mission, divide it into manageable objectives, assign that mission to a focus session, and review your progress afterward.

The interface takes inspiration from the military command systems and terminology of *86 -EIGHTY-SIX-*. SPEARHEAD is a personal productivity project, not an official app or a product connected to the series.

## What can I do with it?

SPEARHEAD is organised into five sections. Each one has a specific job:

| Section | What it does |
| --- | --- |
| **Command Center** | Start and control your focus timer, choose a mission for the session, see a quick view of your work, and check today's activity. |
| **Mission Control** | Create missions, break them into objectives, set priorities and deadlines, track progress, and search or filter your mission list. |
| **Para-RAID** | Read an in-app activity feed. It records system messages when focus sessions, breaks, and mission events happen. |
| **Operations History** | Review recorded sessions, focus time, averages, your longest session, streaks, weekly activity, and a 35-day activity calendar. Filter the log by date, mission, session type, and outcome. |
| **System Configuration** | Adjust timer lengths, communication preferences, appearance, interface behavior, and your saved data. |

## Main features

### Focus timer

- Start, pause, resume, skip, and reset focus or break sessions.
- Default schedule: **25 minutes of focus, a 5-minute short break, and a 15-minute long break after four focus sessions**.
- Change focus length, break lengths, and the number of focus sessions in a cycle.
- Optionally assign a mission to a focus session. The mission details are saved with that session's record.
- The timer uses timestamps to keep the remaining time accurate when the browser tab is in the background or the page is refreshed.
- Moving between SPEARHEAD sections does not restart the timer.

### Missions and objectives

- Create, edit, archive, restore, and delete missions.
- Add objectives to make larger tasks easier to work through.
- Set mission priorities and deadlines.
- Mark objectives as complete, reopen them, or update them as plans change.
- Search, filter, and sort missions.
- A mission can only be marked complete when it has at least one objective and all of its objectives are complete. Finishing the objectives does not automatically close the mission; the operator confirms the mission completion.

### Para-RAID messages

Para-RAID is an **in-app activity feed**, not a real network connection and not a chat with a character. Its messages are generated by events in SPEARHEAD, such as starting or finishing a focus session or changing a mission.

Messages are grouped into four channels:

- Handler Command
- Squadron Channel
- System Notifications
- Mission Control

You can turn Para-RAID on or off, enable individual channels, and choose Minimal, Standard, or Frequent message levels. Optional notification sounds and browser notifications can also be enabled. Browser notifications require permission from your browser.

### Session history and statistics

SPEARHEAD records completed, skipped, and reset sessions in Operations History. Records include session times, the actual active duration, the outcome, and the assigned mission details when available. Paused time is not counted as active focus time.

The history page includes:

- Total completed focus sessions and total focus time.
- Average and longest completed focus sessions.
- Current focus streak.
- Today's and this week's activity.
- A Monday-to-Sunday activity chart.
- A 35-day activity calendar.
- Filters and sorting for the operations log.

Only completed focus sessions count toward focus-time statistics. Older sessions from before detailed session recording was introduced may appear as a legacy count, but do not have individual timestamps or records.

### Appearance and interface options

System Configuration includes two themes:

- **Handler Light** — a darker command frame with brighter display panels.
- **Tactical Dark** — a darker overall interface.

You can also enable or disable the custom targeting cursor and interface animations. The enhanced 3D mosaic page transition is an experimental visual feature and can be disabled separately. SPEARHEAD respects your operating system's reduced-motion preference.

### Backup and restore

Your information is saved in your browser. From **System Configuration → Data Management**, you can:

- Export a JSON backup of your SPEARHEAD data.
- Import a previous SPEARHEAD backup after reviewing its contents.
- Clear SPEARHEAD's saved data from the current browser.

Importing a backup replaces the matching data sections in the current browser. Sections that are not included in the backup are left as they are.

## Getting started

### You will need

- [Node.js](https://nodejs.org/) 18 or newer.
- npm, which is included with Node.js.
- A modern web browser.

### Run SPEARHEAD locally

1. Clone the repository or download the project.
2. Open a terminal in the project folder (the folder containing `package.json`).
3. Install the dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local address printed in the terminal. Vite normally uses `http://localhost:5173`.

### Build for production

To create an optimised production build, run:

```bash
npm run build
```

To serve that build locally for a quick check, run:

```bash
npm run preview
```

## Running the tests

The project includes logic tests for the timer, missions, Para-RAID messages, operations history, interface preferences, and backup validation.

Run them from the project folder:

```bash
node tests/timerLogic.test.mjs
node tests/missionLogic.test.mjs
node tests/communicationLogic.test.mjs
node tests/operationLogic.test.mjs
node tests/interfaceAndData.test.mjs
```

The current project snapshot has **105 passing automated logic checks** across these five test files. These tests check application rules and data handling; they are not a substitute for checking the interface and animations in a real browser.

## Where things live in the project

```text
src/
  components/
    common/          Shared status and cursor components
    communication/   Para-RAID feed and communication settings
    layout/          Sidebar, top bar, main layout, page transition
    missions/        Mission cards, forms, details, and objectives
    settings/        Timer settings and data management
    statistics/      Charts, calendar, statistics, and session log
    timer/           Focus timer display and controls
  hooks/             Timer, mission, communication, history, and UI logic
  pages/             The five main sections of SPEARHEAD
  services/          Browser storage, backup/restore, and notifications
  styles/            Theme variables, layout, components, and responsive rules

tests/               Automated logic tests
```

The main application is built with **React 18** and **Vite 5**. Styling is written in CSS. The enhanced page transition uses a WebGL2 renderer when it is available; if it is unavailable, navigation can fall back to an instant page change.

## Where your data is stored

SPEARHEAD does not currently use an account, a database, or a cloud sync service. Missions, timer state, communication history, operations records, and preferences are saved in the browser's **local storage** on the device and browser profile where you use the app.

This means:

- Your data is not automatically shared between devices or browsers.
- Clearing browser site data may remove your SPEARHEAD information.
- Export a backup regularly if you want to keep a separate copy or move your data to another browser or device.
- Importing a backup is the way to restore data in another browser.

## Current development status

SPEARHEAD is an ongoing personal project. The core timer, mission planner, Para-RAID feed, session history, settings, and browser backup tools are implemented. The enhanced mosaic page transition is still being refined, so its visual behavior and performance may vary across browsers and devices. You can turn it off in **System Configuration → Interface Preferences → Enhanced Page Transitions**.
